## Profile Signal v0.1.0

GitHub Profile READMEへ、公開GitHub Activityから生成した開発状況Widgetを自動挿入する **Profile Signal 初回Release** です。

### 主な機能

- GitHub ActionsによるProfile README自動更新
- TODAY: Commit / PR / Issue集計
- LIVE SIGNAL: 最近の公開Activityと開発状態
- CURRENT FOCUS: 現在もっとも動いているRepository
- DEV PULSE: 直近7日のActivity可視化
- NOW BUILDING: 最近アクティブなRepository
- ACTIVITY STREAM: 最新の公開開発Activity
- DEV RECAP: Weekly / Monthly集計
- `minimal` / `standard` / `full` / `terminal` preset
- `signal` / `minimal` / `terminal` theme
- 日次・週次・月次データ保存

### 導入

1. Assetsから `profile-signal-v0.1.0.zip` をダウンロードします。
2. 自分のGitHub Profile Repository (`<username>/<username>`) のrootへ展開します。
3. `.github/profile-signal.yml` の `YOUR_GITHUB_USERNAME` を自分のGitHub loginへ変更します。
4. 展開したファイルをcommit / pushします。
5. **Actions → Profile Signal → Run workflow** を実行します。
6. README / data / assets の生成結果を確認します。

Release ZIPには既存の `README.md` を含めていないため、ZIP展開だけでプロフィール本文を上書きしません。

### Privacy

v0.1.0は `privacy.public_only: true` のみ対応します。

Private Repository情報を取得して後からマスクする方式ではなく、公開情報だけを収集します。標準構成ではAPI SecretやPATは不要です。
