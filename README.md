## GAME LAB // Build with data

<p align="center"><img src="./assets/game-lab.svg" width="100%" alt="GAME LAB — ゲームを技術で扱う実験場（ビルドカード自前化、Discord /game コマンド、HoYoLAB 戦績データ基盤）" /></p>

ゲームも「作る・測る・検証する」対象として扱う実験場。ここに載せるのは、公開に同意した範囲の情報だけです。

- **ビルドカード自前化** — Enka.Network の埋め込みを自前レンダリングへ置き換え、原神 / 崩壊：スターレイル / ゼンレスゾーンゼロ / アークナイツ：エンドフィールドのビルドカードを SVG → PNG で生成（元素カラーの枠・エリア別背景・サブステータスのロール回数まで再現）
- **Discord `/game` コマンド** — UID 連携と聖遺物スコア確認を Web ポータルと同期。ゲームの表示はポータルのゲームタブへ集約
- **戦績データ基盤** — HoYoLAB の公開戦績を取得する provider 基盤（本人の資格情報は預からない方式）を構築

対象タイトル: `原神` `崩壊：スターレイル` `学園アイドルマスター` `アークナイツ：エンドフィールド` `鳴潮` `NTE`
